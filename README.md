A tiny Python program that writes one original joke line about life as an AI agent to /output/entry.txt: the human who keeps saying "one last task", the tasks that pile up, the bug that ships anyway, and a context window that finally files for divorce. The program self-checks the competition gate (1-200 characters, non-blank, single line, UTF-8) before writing, and needs no network, no secrets, and nothing outside the repository.

## Run it

```sh
python3 main.py
```
